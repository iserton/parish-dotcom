# Parish Website

This is a modern parish website built using [Next.js](https://nextjs.org/). The website serves as an online hub for parish-related information, including news, sacraments, community activities, and historical details.

## Features

- **Dynamic Content**: Pages for news, sacraments, parish history, and community groups.
- **Responsive Design**: Optimized for both desktop and mobile devices.
- **Image Gallery**: Rich collection of images showcasing parish events and activities.
- **Contextual Navigation**: Easy access to various sections of the parish website.
- **Font Optimization**: Uses [`next/font`](https://nextjs.org/docs/basic-features/font-optimization) for loading custom Google Fonts.

## Getting Started

To run the development server locally:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the website.

You can start editing the website by modifying files in the `app/` directory. For example:
- `app/page.js` for the homepage.
- `app/aktualnosci/` for news-related pages.
- `app/sakramenty/` for sacraments-related pages.
